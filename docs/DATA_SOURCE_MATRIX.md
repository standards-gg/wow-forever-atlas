for full detail and citations; this is the decision-oriented summary.
"Recommended use" reflects a judgment call for this project, not a
license/technical fact by itself — re-derive it if the underlying facts
change (especially the official-beta-vs-private-server question in
`PROJECT_RECON.md` §0).

## Gaps no source currently fills

- **NPC and GameObject spawn positions** — confirmed absent from client DB2
  (`SOURCE_WAGO.md` §3.4). No source investigated in Phase 0 supplies this
  for Forever specifically. This is the top open sourcing problem for Phase 1.
- **The ~1,200 Forever-original quests** (per the original brief) — confirmed
  absent, or present without coordinates, in every community dataset checked
  (ATT, QuestieDB, Quest TLDR all describe Forever-added content as
  incomplete/in-progress). No source currently has this data at production
  quality; it will need either our own extraction pipeline against the live
  beta client, community contribution tooling, or waiting for upstream
  (ATT/QuestieDB) coverage to mature before/after the 2026-11-04 launch.
- **Quest narrative/objective text at the DB2 level** — table not identified
  (`SOURCE_WAGO.md` Open Question #1); likely needs to come from ATT or
  community sources rather than raw client data.
