# Importer: Freier Bund

**Status: does not exist and should not — Freier Bund is a historical
UX/information-architecture reference, not a data source.**

Freier Bund's community site covers a different, unrelated, inactive
Classic/Cataclysm-era private server ("Der Freie Bund," realm "Alleria") —
not WoW: Forever. Its data (quest text, NPC info, etc.) describes a
different game entity entirely and has no place in this project's
database. This directory exists only to satisfy the requested
`importers/{source}/` folder structure.

What Freier Bund *did* inform (properly, as a product/IA reference rather
than data import): the entire "what is around me?" product principle (see
`docs/PROJECT_RECON.md`, `docs/GEOGRAPHIC_GRAPH.md`'s "what is around me?"
query section), modeled directly on its confirmed "Umgebung" (surroundings)
tab pattern — a categorized, counted, cross-linked roster of every entity
type in a zone. See `docs/SOURCE_FREIERBUND.md` for the full research.
